math-team-battle v0.7.3 - 유사문제 생성 + Blaze 전 안전 준비

[핵심 변경]
1. 문제 카드마다 "유사문제" 버튼 추가
   - 조건만 바꾸기
   - 같은 개념 새 문제
   - 조금 더 쉽게
   - 조금 더 어렵게
   - 응용문제로 변형

2. 여러 문제 선택 후 "유사문제 일괄" 생성
   - 한 번에 원본 최대 10개
   - 전체 생성 결과 최대 20개
   - 원본 1개당 생성 수 선택

3. 유사문제는 Gemini 무료 엔진으로 생성
   - 기존 AI 문제 만들기 화면에서 저장한 Gemini API 키/모델 사용
   - 정답/보기/해설을 다시 검증하도록 프롬프트 강화
   - 원본과 완전히 같은 문제, 보기 중복, 형식 오류 자동 제외
   - 저장 시 parentQuestionId / variantType / aiProvider / aiModel 기록

4. OpenAI 고급 엔진 UI 준비
   - AI 문제 만들기와 유사문제 화면에 "OpenAI 고급" 자리 표시
   - 현재는 의도적으로 잠금 상태
   - OpenAI 유료 키는 브라우저에 넣지 않음
   - Blaze 보안 점검 후 서버 방식으로 연결 예정

5. AI 연속 클릭 보호
   - 이 브라우저 기준 분당 5회 / 하루 60회
   - Gemini 새 문제 생성, AI 2차 검수, 유사문제 생성에 적용
   - 실수 방지용 localStorage 제한이며 보안 하드캡은 아님

6. Blaze 전 보안 점검 문서 추가
   - SECURITY_BEFORE_BLAZE.md 확인
   - 현재 RTDB 방 읽기 규칙은 Blaze 전에 별도 보안 패치 권장

[중요]
- 이번 버전에서는 Firebase 보안 규칙을 변경하지 않았습니다.
- Blaze 업그레이드도 아직 하지 마세요.
- OpenAI API 키를 프로젝트 파일에 넣지 마세요.

[적용]
기존 프로젝트에 이 ZIP의 파일을 그대로 덮어씁니다.

추가 npm 설치: 없음
Firebase rules 재배포: 없음

CMD:
npm run build
firebase deploy --only hosting

4. 정답과 해설 확인
5. 저장 후 원래 분야/주제 아래에 들어왔는지 확인
6. 문제 2~3개 체크 -> "유사문제 일괄" 테스트
