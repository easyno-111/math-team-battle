v0.12.2 패치 — 수식 표시 / OpenAI 고급 생성 / 퀴즈 모드

v0.11.0(데이터베이스 규칙 긴급 수정 포함)에서 바뀐 파일 패치입니다.
1. ZIP 안의 파일을 기존 프로젝트 최상위에 덮어쓰세요.
2. OPENAI_SETUP.md를 열고 설치·서버 설정·Secret 등록·배포를 순서대로 진행하세요.

변경 사항
- AI 수식의 $...$, $$...$$, \(...\), \[...\] 구분자를 해석.
- 분수, 루트, 제곱/아래첨자, 기본 수학 기호 표시와 편집 미리보기 개선.
- 일반 AI 문제, 유사문제, AI 검수, 퀴즈 5유형 생성에서 고급 OpenAI 선택 가능.
- 매 요청마다 관리자 로그인 비밀번호 검증. OpenAI 키는 Firebase Secret 보관.
- 서버 관리자 UID 허용 목록, 중복/동시 요청 방지, 분당3회/하루60회 제한.
- 순서 카드: 위치 번호를 ‘1번째’ 칸으로 분리하여 숫자 답과 구분.
- ‘퀴즈앤 모드’ → ‘퀴즈 모드’. 실제 화면 버전 v0.12.2 표시.

OpenAI 서버를 아직 설정하지 않고 화면 수정부터 적용하려면:
  npm install
  npm run build
  firebase deploy --only "hosting,database"
이 경우 기본 Gemini는 사용할 수 있지만 고급 OpenAI는 서버 설정 후 작동합니다.

전체 ZIP에 포함된 기존 dist는 배포 전 반드시 다시 빌드하세요.
검증 및 환경 제한은 OPENAI_SETUP.md 마지막 부분에 적었습니다.
