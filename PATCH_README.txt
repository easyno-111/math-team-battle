수학 팀 배틀 v0.3.1 덮어쓰기 패치

변경 사항
- 저장된 문제에 삭제 기능 추가
- 삭제를 한 번 더 확인하는 안전장치 추가
- 전체 관리자 UI를 둥글둥글한 파스텔톤으로 변경
- 영어식/AI 느낌이 강했던 보조 문구를 자연스러운 한국어로 정리
- Excel 일괄 등록 영역도 같은 파스텔 테마로 통일
- 화면 버전 v0.3.1 표시

적용 방법
1. 이 ZIP의 내용을 기존 math-team-battle 폴더에 그대로 덮어씁니다.
2. 이미 v0.3.0에서 npm install을 했다면 추가 설치는 필요 없습니다.
3. CMD에서 npm run dev 실행

주의
- src/firebase.js는 이 ZIP에 포함하지 않았습니다. 기존 Firebase 설정은 유지됩니다.
